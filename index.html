Step-by-step: how to make a barcode

1. Choose the right format

Code 128 is the safest default because it handles upper and lowercase letters, digits and punctuation. Pick Code 39 only if a system specifically asks for it. Pick EAN-13, UPC-A or EAN-8 when you need a numeric retail-style code.

2. Enter your value

Type or paste the value. The hint under the box tells you what the selected format accepts. Code 39 converts lowercase letters to uppercase for you. Numeric formats accept digits only.

3. Set the size and colors

The standard 3 px bar width suits most screens and desktop printers. Go wider for labels printed small or scanned from a distance. Keep dark bars on a light background; the tool warns you if the contrast is too low to scan.

4. Generate and download

Click Generate barcode. The preview updates as you change options. Download the PNG for Word, Google Docs or slides. Download the SVG for design software or sharp professional printing. You can also copy the image to your clipboard where your browser allows it.

5. Test before you print

Scan the on-screen barcode with a phone scanner app or your actual scanner. Do this before you print a whole sheet of labels.

Expert tips and common mistakes

  • Keep the quiet zone. The blank margin on each side is part of the barcode. This tool adds it, so don't crop it off.
  • Don't stretch the image. Resizing a PNG with unequal width and height distorts the bars. Scale it proportionally, or use the SVG.
  • Print at 100% scale. Browser "fit to page" settings can shrink bars below what a scanner can read.
  • Avoid tiny PNGs. If you must shrink a barcode, use the Resize Image tool and keep the aspect ratio locked.
  • Use dark on light. Red bars or pale colors on white often fail under scanner lasers.
  • Match the system. If your inventory software expects Code 128, don't switch to Code 39 because it looks simpler.
  • Don't guess retail numbers. An EAN-13 or UPC-A made here is a valid pattern, but it isn't a registered product number.
  • Mind the length. Long values make wide barcodes. Shorten the value or use a larger sheet.

Troubleshooting

My barcode won't scan

Check contrast first: use black bars on white. Then increase bar width and height, and make sure the quiet zone wasn't cropped.

I get "check digit" errors on EAN or UPC

You entered the full number and the last digit doesn't match. Remove the last digit and let the tool calculate it, or use the digit shown in the message.

Code 39 says a character isn't supported

Code 39 only allows A-Z, 0-9, space and - . $ / + %. Switch to Code 128 if you need other symbols.

The barcode looks blurry when printed

The PNG was probably scaled up. Download the SVG, or choose a larger bar width before generating.

Copy image does nothing

Some browsers block clipboard image access. Use Download PNG instead.

The barcode is too wide for my label

Shorten the value, choose a narrower bar width, or switch from Code 39 to Code 128, which is more compact.

Nothing happens when I click Generate

Make sure JavaScript is enabled, then read the red status message under the buttons. It names the exact problem.

Glossary

  • Symbology: the rule set for a barcode type, such as Code 128 or EAN-13.
  • Check digit: a final digit calculated from the others, so scanners can catch misreads.
  • Quiet zone: the blank margin on each side of the bars.
  • Module: the width of the narrowest bar. Other bars are multiples of it.
  • EAN / UPC: numeric retail barcode families used on packaged products.
  • GS1: the organization that issues official company prefixes for retail codes. See gs1.org.
